# ClinicDesk

Clinic Management System built using PHP and MySQL.

## Features

- Authentication & RBAC
- Doctor Management
- Appointment Booking
- Prescription System
- Reports & CSV Export
- Secure File Uploads
- CSRF Protection
- SQL Injection Prevention
- XSS Protection

## Requirements

- PHP 8+
- MySQL 8+
- Apache

## Installation

1. Import clinicdesk_db.sql
2. Configure database.php
3. Start Apache & MySQL
4. Open:
   http://localhost/clinicdesk
